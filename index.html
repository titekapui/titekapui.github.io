Tentang Titek Apui Monitor

Sistem pemantauan titik api berbasis data satelit NASA FIRMS untuk deteksi dini kebakaran hutan dan lahan di wilayah Aceh. Dokumen dan aplikasi ini disusun dengan bahasa yang sederhana — dapat langsung dipahami oleh masyarakat gampong dan petani penggarap lahan.

01 // RINGKASAN EKSEKUTIF

Apa Itu Titek Apui Monitor

Titek Apui Monitor adalah sistem pemantauan titik api (hotspot) berbasis peta digital yang menampilkan data deteksi kebakaran secara mendekati waktu nyata (near real-time) untuk wilayah Aceh. Sistem ini mengolah data resmi dari satelit milik NASA — Suomi NPP, NOAA-20, NOAA-21 (sensor VIIRS), serta Terra dan Aqua (sensor MODIS) — melalui layanan FIRMS (Fire Information for Resource Management System), lalu menyajikannya dalam antarmuka peta interaktif yang mudah diakses melalui komputer maupun ponsel.

Sistem ini dikembangkan secara mandiri setelah menyaksikan langsung dampak kebakaran lahan gambut di Cot Seumeureung, Kecamatan Samatiga, Kabupaten Aceh Barat pada awal tahun 2026. Halaman ini disusun sebagai dokumentasi menyeluruh mengenai latar belakang, arsitektur, dan manfaat sistem.

02 // LATAR BELAKANG

Mengapa Sistem Ini Dibuat

Kabupaten Aceh Barat dan wilayah pesisir barat-selatan Aceh memiliki kawasan lahan gambut yang rentan terhadap kebakaran, terutama pada musim kemarau. Kebakaran lahan gambut sulit dideteksi secara visual pada tahap awal karena sering terjadi di area terpencil dan berupa pembakaran di bawah permukaan (smoldering) sebelum meluas menjadi kebakaran terbuka.

Peristiwa kebakaran lahan gambut di Cot Seumeureung menjadi titik tolak penyusunan sistem ini. Padahal, data satelit deteksi titik api dari NASA FIRMS sesungguhnya tersedia secara terbuka dan gratis, namun belum banyak dimanfaatkan secara langsung karena format data mentah (CSV) yang tidak mudah dibaca oleh pengguna non-teknis.

Titek Apui Monitor menjembatani kesenjangan tersebut dengan menyajikan data yang sama dalam bentuk visual peta yang sederhana, cepat, dan dapat langsung digunakan tanpa memerlukan keahlian teknis khusus.
03 // RUMUSAN MASALAH

Kendala yang Ingin Dijawab

  • Informasi titik api dari sumber resmi (NASA FIRMS) tersedia dalam format data mentah yang sulit diakses langsung oleh masyarakat maupun aparat gampong.
  • Belum ada kanal pemantauan titik api yang berbahasa lokal (Aceh) dan disesuaikan dengan cakupan wilayah Aceh secara spesifik.
  • Deteksi dini kebakaran lahan gambut memerlukan pemantauan berkelanjutan yang sulit dilakukan secara manual oleh petugas di lapangan.
  • Koordinasi antar-pihak (BPBD, Dinas Kehutanan, pemerintah gampong, petani) memerlukan rujukan data lokasi yang cepat, konsisten, dan mudah dibagikan.
04 // DESKRIPSI SOLUSI

Fitur Utama

Titek Apui Monitor adalah aplikasi web yang dapat diakses langsung melalui tautan tanpa instalasi. Pengguna dapat memilih cakupan wilayah, memilih sumber satelit, serta melihat detail setiap titik seperti perkiraan suhu, tingkat kepercayaan deteksi, energi kebakaran, waktu deteksi, dan perkiraan nama lokasi.

Peta Interaktif
Tampilan peta jalan, citra satelit, dan mode gelap.
Multi-Satelit
Gabungan atau pilihan satelit: Suomi NPP, NOAA-20, NOAA-21, Terra & Aqua.
Skala Energi
Ukuran penanda menyesuaikan besar energi kebakaran (FRP).
Clustering
Titik yang padat dikelompokkan otomatis agar peta tetap terbaca.
Tiga Bahasa
Antarmuka Bahasa Aceh, Indonesia, dan Inggris.
Lokasi Saya
Melihat posisi pengguna relatif terhadap titik api terdekat.
05 // ARSITEKTUR TEKNIS

Bagaimana Sistem Bekerja

KomponenDeskripsi
Sumber DataNASA FIRMS — data deteksi titik api dari satelit Suomi NPP, NOAA-20, NOAA-21 (VIIRS) serta Terra dan Aqua (MODIS), diperbarui berkala oleh NASA.
BackendSkrip pengolah data (Google Apps Script) yang mengambil data mentah dari NASA FIRMS, menyaring data sesuai batas wilayah, lalu menyediakannya bagi antarmuka peta.
FrontendAntarmuka peta berbasis web menggunakan Leaflet.js, dengan visualisasi interaktif, penanda berskala energi, legenda, pengelompokan titik, dan dukungan tiga bahasa.
AksesibilitasAplikasi web murni, dapat diakses langsung melalui tautan di peramban tanpa instalasi maupun biaya berlangganan.

Alur Kerja Data (Data Pipeline)

Setiap kali peta dibuka atau diperbarui, sistem menjalankan rangkaian proses berikut secara otomatis dalam hitungan detik:

Pengambilan Data Mentah
Backend menarik berkas CSV terbaru langsung dari server NASA FIRMS sesuai satelit yang dipilih, berisi seluruh titik deteksi panas dalam 24 jam terakhir.
Penyaringan Spasial
Dari ribuan baris data global, sistem menyaring hanya koordinat yang jatuh di dalam batas wilayah Aceh, Indonesia, atau global.
Deduplikasi Koordinat
Titik yang terdeteksi berulang oleh sensor yang sama pada lintasan tumpang tindih disaring hingga presisi ±11 meter, agar peta tidak menampilkan penanda ganda.
Konversi Waktu ke WIB
Waktu akuisisi citra (UTC) dikonversi otomatis ke Waktu Indonesia Barat agar sesuai waktu operasional di lapangan.
Estimasi Suhu Permukaan
Brightness temperature dari kanal inframerah sensor dikonversi dari Kelvin ke Celsius agar mudah dipahami.
Visualisasi Berskala Energi
Radius penanda dihitung memakai fungsi akar kuadrat terhadap nilai FRP, sehingga luas lingkaran proporsional terhadap energi kebakaran sesungguhnya.
Pengelompokan Dinamis
Saat kepadatan titik tinggi, penanda berdekatan digabung menjadi satu simpul beranotasi jumlah, dan pecah kembali saat pengguna memperbesar peta.
Pengayaan Lokasi On-Demand
Nama lokasi (desa/kecamatan) hanya diminta ke layanan Nominatim saat popup suatu titik dibuka, menghemat kuota layanan pihak ketiga.

Fusi Multi-Satelit

VIIRS pada Suomi NPP, NOAA-20, dan NOAA-21 memiliki resolusi spasial 375 meter per piksel, mampu mendeteksi titik api lebih kecil dan bergerak lebih cepat. MODIS pada Terra dan Aqua memiliki resolusi 1 kilometer namun riwayat data historis lebih panjang. Dengan opsi penggabungan maupun pemilihan satelit individual, sistem memungkinkan silang-verifikasi antar sumber — titik yang terdeteksi konsisten oleh lebih dari satu satelit memberikan tingkat keyakinan lebih tinggi.

06 // KEANDALAN & SUMBER DATA

Dari Mana Data Berasal

Seluruh data titik api yang ditampilkan bersumber dari NASA FIRMS, layanan yang telah digunakan secara luas oleh lembaga penanggulangan bencana dan kehutanan di berbagai negara, termasuk oleh Kementerian Lingkungan Hidup dan Kehutanan Republik Indonesia serta Badan Restorasi Gambut dan Mangrove dalam pemantauan karhutla nasional. Titek Apui Monitor tidak menggantikan sumber data resmi tersebut, melainkan menghadirkannya dalam bentuk yang lebih mudah diakses khusus untuk konteks kebutuhan pemantauan di wilayah Aceh.

07 // MANFAAT DAN DAMPAK

Untuk Siapa Sistem Ini Berguna

  • Mempercepat identifikasi lokasi titik api di wilayah Aceh Barat dan Aceh secara umum, sebagai bahan rujukan awal sebelum verifikasi lapangan.
  • Mendukung koordinasi antar-pemangku kepentingan (BPBD, Dinas Kehutanan, Satpol PP dan Damkar, pemerintah gampong, kelompok masyarakat) dengan rujukan peta yang seragam.
  • Menjadi alat bantu edukasi dan sosialisasi kepada masyarakat gampong mengenai risiko kebakaran lahan di sekitar wilayah mereka.
  • Berpotensi diintegrasikan dengan sistem peringatan dini yang sudah ada, atau dijadikan rujukan pelengkap bagi siapa pun yang terlibat dalam pemantauan karhutla.
08 // PETA JALAN PENGEMBANGAN

Rencana ke Depan

  • Notifikasi otomatis (Telegram/WhatsApp) kepada perangkat gampong ketika titik api terdeteksi di radius tertentu wilayah mereka.
  • Riwayat dan tren titik api harian/mingguan untuk mendukung analisis pola kebakaran musiman.
  • Fitur ekspor data (PDF/CSV) untuk keperluan pelaporan resmi.
  • Peningkatan keandalan sistem melalui mekanisme cache agar lebih tahan lonjakan akses saat musim kemarau.
09 // PELUANG KOLABORASI

Terbuka untuk Bekerja Sama

Sistem ini saat ini dikembangkan dan dioperasikan secara mandiri tanpa biaya kepada pengguna. Untuk keberlanjutan dan perluasan manfaat, terbuka ruang kolaborasi dengan berbagai pihak, antara lain masukan kebutuhan teknis dari pihak yang berkecimpung dalam penanggulangan bencana, kolaborasi pengembangan fitur dengan komunitas teknologi atau akademisi, serta dukungan operasional apabila sistem akan diadopsi lebih luas.
